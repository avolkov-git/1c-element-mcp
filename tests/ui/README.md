# Проверки интерфейса

Node.js 22 нужен только для разработки и CI, не для запуска MCP.

```sh
cd tests/ui
npm ci --ignore-scripts
npm test
```

Тесты выполняют production HTML/JavaScript в jsdom с подменёнными HTTP-ответами
и часами. Проверяются формы, защита от повторного запроса, состояния ошибок,
секрет Console, права действий, источники обновлений, перезапуск, тема и
трёхсекундные тосты. API и упаковка проверяются Python-тестами.

Проверка макета в браузере: все четыре раздела, светлая и тёмная тема,
широкое окно и ширины 375/320 px. Нужно проверить отсутствие горизонтального
переполнения, видимость иконок, фиксированное положение тостов и сохранение
темы после обновления страницы. Не сохранять тестовые credentials или
разрешения действий в рабочей конфигурации ради визуальной проверки.

В Docker кнопка перезапуска остаётся недоступной: существующий серверный
API поддерживает перезапуск только установки Windows Server. Его сценарий
проверяется в jsdom и серверных тестах, а не перезапуском Docker из браузера.
