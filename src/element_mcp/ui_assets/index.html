Удалённый сервер Element

Нужен для доступа к Панели управления из VS Code или другого внешнего клиента.

Укажите базовый адрес Console, обычно он заканчивается на /console. Полный путь /console/api/v2 тоже подойдёт.

Секрет не возвращается в браузер или агенту после сохранения.

Диагностика сервера Element

Локальные состояние, место на диске и журнальные файлы экземпляра.

Это рабочий каталог установленного экземпляра с папками config и logs, а не каталог дистрибутива.

Журнал событий приложения

Нужна отдельная внутренняя учётная запись экземпляра. Client ID и Client Secret Панели управления здесь не подходят.

Укажите адрес сервера до /manager/api/v1 или /manager/api/v2.

На Windows пароль защищается средствами ОС. Он не возвращается в браузер или агенту.
