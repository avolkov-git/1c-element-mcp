Нужен для доступа к Панели управления из VS Code или другого внешнего клиента.

Секрет не возвращается в браузер или агенту после сохранения.

Доступные операции

Перед каждой операцией MCP покажет точную цель и риски, дождётся отдельного подтверждения и выдаст одноразовое разрешение на 5 минут. Запросы на изменение не повторяются автоматически.
