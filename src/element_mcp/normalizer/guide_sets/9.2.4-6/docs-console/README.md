# Management Console 9.2.4-6: полный корпус

Это документация и поисковый корпус встроенного проекта `Management-console` (`Vendor: e1c`, `Name: console`, `CompatibilityMode: 8.0`). Исходники извлечены из серверного модуля `com.e1c.g5rt.server.paasmanager-9.2.4-6.jar`.

## Полнота среза

- 4 283 встроенных файла;
- 2 246 YAML-описаний элементов;
- 1 782 XBSL-модуля и 11 XBQL-запросов;
- 13 558 индексированных объявлений методов;
- 3 472 импорта;
- 466 HTTP-операций, найденных в 45 HTTP-сервисах;
- 266 нормализованных страниц официального Console API;
- 48 корневых подсистем/областей.

Бинарные ресурсы сохранены в `versions/9.2.4-6/source`. Все текстовые исходники включены в JSONL и поисковые индексы. Для каждого корневого раздела автоматически создан исчерпывающий список файлов, видов элементов, методов и HTTP-маршрутов в `versions/9.2.4-6/subsystems`.

## Навигация

- `guides` — объяснение архитектуры и сквозных сценариев.
- `versions/9.2.4-6/source/e1c/console` — точные исходники.
- `versions/9.2.4-6/normalized/official-api` — официальная API-документация в Markdown.
- `versions/9.2.4-6/reference/elements.jsonl` — каталог прикладных элементов.
- `reference/http-routes.jsonl` — маршруты, HTTP-методы, handlers и access control.
- `reference/methods.jsonl` — методы с файлами и строками.
- `reference/imports.jsonl` — граф зависимостей модулей.
- `reference/subsystems.jsonl` и `subsystems/*.md` — полное покрытие подсистем.
- `corpus` — документы, чанки, FTS и векторы.

## Правило чтения

Аналитические guides объясняют систему, но при реализации окончательным источником служат YAML/XBSL текущей версии. Для публичного контракта дополнительно проверяется официальная страница API. Маршруты из YAML указывают внутренний `RootUrl`; фактический внешний префикс зависит от публикации сервера и обычно отражён в официальной документации как `/console/api/...`.
