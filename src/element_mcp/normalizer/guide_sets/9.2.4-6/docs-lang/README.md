# Корпус языка «1С:Предприятие.Элемент» 9.2

Корпус содержит нормализованную официальную документацию разработчика и стандартной библиотеки. Основной язык модулей — XBSL (`.xbsl`), запросов — XBQL (`.xbql`), декларативное описание прикладных объектов хранится в YAML.

## Где что находится

- `versions/9.2.4-6/normalized/topics` — руководство разработчика, синтаксис, прикладные объекты, UI, интеграции, IDE и эксплуатационные темы.
- `versions/9.2.4-6/normalized/stdlib` — типы, свойства, методы, глобальный контекст и язык запросов.
- `versions/9.2.4-6/documents.jsonl` — документы текущего среза до чанкинга. В metadata у них `source_version: 9.2`.
- `corpus/chunks.jsonl` — атомарные фрагменты для LLM/RAG.
- `corpus/index.sqlite` — FTS5/BM25.
- `corpus/vectors.f16.npy` — локальный векторный индекс.
- `guides` — карта языка и правила работы агента.

## Граница достоверности

Нормализованный Markdown получен из поставки документации 9.2. Ссылки и изображения сохранены как ссылки на исходный сайт/путь поставки. Для точного имени типа или сигнатуры всегда предпочитать страницу `stdlib`; для объяснения концепции — `topics`. Если сведения расходятся с LSP версии `9.2.4-6`, при проверке кода приоритет имеет диагностика LSP, а расхождение следует зафиксировать как версионное.
