# Карта поиска по языковому корпусу

## Как выбирать источник

| Вопрос | Предпочтительный источник |
|---|---|
| Синтаксис инструкции или литерала | `topics`, раздел языка |
| Точная сигнатура метода/свойства | `stdlib/element/xbsl` |
| Запросы и виртуальные таблицы | `stdlib/element/xbql` и темы XBQL |
| Структура прикладного объекта | тема соответствующего объекта плюс YAML-примеры Console |
| UI-компонент и событие | темы UI плюс LSP XCore-модели |
| Отличие от BSL 8.x | специальные сравнительные темы, не память агента |
| Ошибка конкретного проекта | LSP diagnostics плюс точный исходник |

## Полезные поля JSONL

- `kind=standard-library` — API стандартной библиотеки;
- `kind=language-topic` — объяснение концепции и сценарии;
- `route` — исходный маршрут страницы;
- `modified` — дата обновления официальной страницы;
- `sha256` — обнаружение изменения между версиями;
- `logical_id` — сопоставление одной темы в разных релизах.

## Версионный ответ

Если поиск возвращает несколько версий одного `logical_id`, агент должен:

1. выбрать `is_current=true` для текущей разработки;
2. при миграции сравнить тексты и release diff;
3. явно назвать версию, если поведение изменилось;
4. не объединять сигнатуры разных версий в один ответ.
