# Версионирование

Начальная версия проекта: `0.0.0`.

Каждая завершённая итерация разработки меняет версию по правилам Semantic Versioning:

- `PATCH` (`0.1.0` → `0.1.1`): исправления без нового публичного поведения;
- `MINOR` (`0.1.0` → `0.2.0`): новые инструменты и совместимые возможности;
- до `1.0.0` несовместимое изменение публичного контракта также повышает `MINOR` и описывается в changelog;
- `1.0.0` обозначит первый стабильный публичный контракт.

Версия в `pyproject.toml` служит источником истины. Код сервера получает её через метаданные установленного пакета.

В конце итерации нужно:

1. выбрать следующий номер версии;
2. изменить `project.version` в `pyproject.toml`;
3. добавить датированную запись в `CHANGELOG.md`;
4. проверить версию тестом;
5. после принятия итерации создать Git-тег `v<version>`.
