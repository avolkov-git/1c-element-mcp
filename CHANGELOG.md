# История изменений

Проект следует [Semantic Versioning](https://semver.org/).

## [0.7.0] - 2026-07-20

- Добавлен read-only клиент API Панели управления и инструменты проверки подключения, списка пространств, каталога проектов пространства и чтения одного проекта.
- MCP агрегирует идентификаторы из `/api/v2/spaces/{SpaceId}/projects` с полными метаданными `/api/v2/projects/{ProjectId}` и различает пустой список, `401`, `403`, `404` и сетевую недоступность.
- Поддержаны окружение, отдельный `console.json`, настройки Element/VS Code и provisioning context; выбранное пространство может определяться по `1C.projectId`.
- В режиме `stdio` MCP обнаруживает настройки только в известных файлах текущего workspace. Для HTTP-службы Windows путь к настройкам IDE задаётся установщику явно.
- Client-Secret и access token не являются аргументами MCP tools и не возвращаются агенту. Windows-конфигуратор хранит Client-Secret через DPAPI LocalMachine и ограничивает ACL файла.
- Добавлены повторное получение токена после `401`, проверка TLS по умолчанию и поддержка собственного CA bundle для закрытых контуров.

## [0.6.0] - 2026-07-20

- Добавлено безопасное подключение локального исходного проекта 1С:Предприятие.Элемент без изменения его файлов.
- MCP распознаёт `Project.yaml`/`Проект.yaml`, подсистемы, YAML-виды элементов и связанные модули XBSL/XBQL.
- Добавлены обзор проекта, фильтруемый список элементов, ограниченный текстовый поиск и построчное чтение исходников.
- Все файловые операции ограничены подключённым корнем, разрешёнными текстовыми форматами и лимитами размера.
- В server instructions закреплён Element-aware процесс: сначала метаданные YAML, затем связанные модули и код.
- Имя MCP-сервера расширено с документационного на общее `1C Element`.

## [0.5.0] - 2026-07-20

- Полный безопасный сценарий проверки, создания, подключения и использования нормализованной документации встроен в MCP server instructions.
- Codex и другие клиенты, поддерживающие MCP instructions, получают процесс автоматически при подключении; отдельный Skill больше не является обязательной зависимостью.
- Описания инструментов закрепляют явное согласие на тяжёлую сборку, мониторинг до терминального состояния, безопасную отмену и последовательность поиска и чтения.
- Протокольный тест проверяет инструкции и ограничения через настоящий MCP-сеанс `stdio`.

## [0.4.1] - 2026-07-20

- Переключение на удалённый `origin` теперь сохраняется сразу, без дополнительного нажатия «Проверить обновления».
- Во время переключения UI показывает состояние операции, после успеха явно подтверждает новый источник.
- При изменённом локальном пути основная кнопка называется «Сохранить и проверить», поэтому момент применения настройки больше не скрыт.

## [0.4.0] - 2026-07-20

- В локальный UI добавлен выбор доверенного Git-каталога для обновлений и возврат к удалённому `origin`.
- Нажатие «Проверить обновления» сохраняет изменённый путь и автоматически устанавливает более новую локальную версию.
- Выбранный источник хранится в общей конфигурации MCP и читается отдельным заданием Windows Updater при каждом запуске.
- Перед сохранением проверяются абсолютный путь, Git-репозиторий, ветка `master`, имя проекта и корректная SemVer-версия.
- Установочный источник остаётся резервным значением для конфигураций, которые ещё не выбирали источник через UI.

## [0.3.1] - 2026-07-20

- Исправлен запуск MCP через Windows Task Scheduler: штатный вывод Uvicorn в stderr больше не завершает `run-server.ps1` в Windows PowerShell 5.1.
- Сценарий запуска возвращает Task Scheduler настоящий код завершения процесса MCP.

## [0.3.0] - 2026-07-20

- Добавлен локальный UI состояния MCP по корневому адресу HTTP-сервера.
- UI автоматически проверяет наличие новой SemVer-версии и позволяет запустить обновление одной кнопкой.
- Добавлено безопасное обновление через отдельное задание Windows Task Scheduler с перезапуском MCP и откатом при ошибке.
- Источником обновлений может быть удалённый `origin` или локальный Git-каталог для закрытого контура.
- Windows-установщик поддерживает первую установку из локального Git-источника и ждёт запуск сервера до 15 секунд.
- Ответы обновляющего API защищены локальным host-check, процессным токеном и строгой Content Security Policy.

## [0.2.5] - 2026-07-20

- Windows-установщик больше не содержит списка разрешённых minor-версий Python.
- `py.exe` выбирает самый новый установленный Python 3, после чего установщик проверяет единое требование проекта `>=3.11`.

## [0.2.4] - 2026-07-20

- Исправлена проверка доступных версий Python через `py.exe` в Windows PowerShell 5.1.
- Отсутствие Python 3.12 больше не прерывает установку: установщик корректно переходит к Python 3.11.

## [0.2.3] - 2026-07-20

- Исправлен запуск `install-windows.ps1` в Windows PowerShell 5.1 с русской системной кодовой страницей.
- Установщик сделан ASCII-совместимым, а тест запрещает появление в нём зависимых от кодировки символов.

## [0.2.2] - 2026-07-20

- Добавлен повторно запускаемый PowerShell-установщик для Windows Server.
- Установщик регистрирует MCP в Task Scheduler от `SYSTEM`, хранит данные в `ProgramData` и слушает `127.0.0.1:9900`.
- CI расширен на Windows для Python 3.11 и 3.12.

## [0.2.1] - 2026-07-20

- Порт Streamable HTTP по умолчанию изменён с `8000` на `9900`.
- Явный `--port` и переменная `ELEMENT_MCP_PORT` по-прежнему имеют приоритет.

## [0.2.0] - 2026-07-20

- Сервер теперь запускается без предварительно настроенного корпуса.
- Добавлены проверка корпуса и подключение существующего корпуса.
- Добавлен поиск серверных компонентов Element в стандартных каталогах Windows и Linux.
- Добавлена фоновая локальная нормализация языка, Management Console и серверного бандла.
- В поставку нормализатора включены наши аналитические руководства для Element 9.2.4-6.
- Добавлены атомарная сборка, полная валидация и автоматическое подключение успешного результата.
- Добавлена эталонная проверка 9.2.4-6 по 9 925 документам, 59 522 чанкам и хешам индексов.

## [0.1.0] - 2026-07-20

- Добавлен MCP-сервер на стабильной ветке официального Python SDK.
- Добавлены транспорты `stdio` и stateless Streamable HTTP.
- Добавлены read-only инструменты `get_corpus_info`, `search_docs` и `get_document`.
- Добавлен гибридный поиск SQLite FTS5 и по локальному векторному индексу.
- Добавлены тестовый корпус, модульные тесты и протокольный тест через `stdio`.
- Добавлена CI-проверка Python 3.11 и 3.12 без закрытого корпуса документации.

## [0.0.0] - 2026-07-20

- Начальная пустая версия репозитория.
