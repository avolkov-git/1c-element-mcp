# История изменений

Проект следует [Semantic Versioning](https://semver.org/).

## [0.3.1] - 2026-07-20

- Исправлен запуск MCP через Windows Task Scheduler: штатный вывод Uvicorn в stderr больше не завершает `run-server.ps1` в Windows PowerShell 5.1.
- Сценарий запуска возвращает Task Scheduler настоящий код завершения процесса MCP.

## [0.3.0] - 2026-07-20

- Добавлен локальный UI состояния MCP по корневому адресу HTTP-сервера.
- UI автоматически проверяет наличие новой SemVer-версии и позволяет запустить обновление одной кнопкой.
- Добавлено безопасное обновление через отдельное задание Windows Task Scheduler с перезапуском MCP и откатом при ошибке.
- Источником обновлений может быть удалённый `origin` или локальный Git-каталог для закрытого контура.
- Windows-установщик поддерживает первую установку из локального Git-источника и ждёт запуск сервера до 15 секунд.
- Ответы обновляющего API защищены локальным host-check, процессным токеном и строгой Content Security Policy.

## [0.2.5] - 2026-07-20

- Windows-установщик больше не содержит списка разрешённых minor-версий Python.
- `py.exe` выбирает самый новый установленный Python 3, после чего установщик проверяет единое требование проекта `>=3.11`.

## [0.2.4] - 2026-07-20

- Исправлена проверка доступных версий Python через `py.exe` в Windows PowerShell 5.1.
- Отсутствие Python 3.12 больше не прерывает установку: установщик корректно переходит к Python 3.11.

## [0.2.3] - 2026-07-20

- Исправлен запуск `install-windows.ps1` в Windows PowerShell 5.1 с русской системной кодовой страницей.
- Установщик сделан ASCII-совместимым, а тест запрещает появление в нём зависимых от кодировки символов.

## [0.2.2] - 2026-07-20

- Добавлен повторно запускаемый PowerShell-установщик для Windows Server.
- Установщик регистрирует MCP в Task Scheduler от `SYSTEM`, хранит данные в `ProgramData` и слушает `127.0.0.1:9900`.
- CI расширен на Windows для Python 3.11 и 3.12.

## [0.2.1] - 2026-07-20

- Порт Streamable HTTP по умолчанию изменён с `8000` на `9900`.
- Явный `--port` и переменная `ELEMENT_MCP_PORT` по-прежнему имеют приоритет.

## [0.2.0] - 2026-07-20

- Сервер теперь запускается без предварительно настроенного корпуса.
- Добавлены проверка корпуса и подключение существующего корпуса.
- Добавлен поиск серверных компонентов Element в стандартных каталогах Windows и Linux.
- Добавлена фоновая локальная нормализация языка, Management Console и серверного бандла.
- В поставку нормализатора включены наши аналитические руководства для Element 9.2.4-6.
- Добавлены атомарная сборка, полная валидация и автоматическое подключение успешного результата.
- Добавлена эталонная проверка 9.2.4-6 по 9 925 документам, 59 522 чанкам и хешам индексов.

## [0.1.0] - 2026-07-20

- Добавлен MCP-сервер на стабильной ветке официального Python SDK.
- Добавлены транспорты `stdio` и stateless Streamable HTTP.
- Добавлены read-only инструменты `get_corpus_info`, `search_docs` и `get_document`.
- Добавлен гибридный поиск SQLite FTS5 и по локальному векторному индексу.
- Добавлены тестовый корпус, модульные тесты и протокольный тест через `stdio`.
- Добавлена CI-проверка Python 3.11 и 3.12 без закрытого корпуса документации.

## [0.0.0] - 2026-07-20

- Начальная пустая версия репозитория.
